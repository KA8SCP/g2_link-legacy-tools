# MonLink patch distribution

See [interlock documentation](../docs/MONLINK-INTERLOCK.md). MonLink is separate from the dashboard installer. Operator-supplied program/patch artifacts are held outside the dashboard release pending their existing licensing review. Neither the complete program nor an executable patch is published by this dashboard update. Earlier review documents describe supplied artifacts, not assets available for installation from this release.

[Technical review for Ken WB4FAY](../docs/MONLINK-PATCH-REVIEW.md) explains each change, no-marker compatibility and the remaining regression tests.
