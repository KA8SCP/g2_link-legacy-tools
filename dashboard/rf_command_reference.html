RF Command Reference

Send commands on the WB1GOF module you want to control. URCALL commands use exactly eight characters. In the examples below, each · represents a space; do not enter the dots. After issuing a command, restore URCALL to CQCQCQ for normal conversations.

URCALL commands

ActionDPlusg2_link
Link REF050CL — REF050 C DCS049CO — DCS049 C
XRF049CO — XRF049 C
Unlink ·······U ·······T
Link information ·······I ·······W

The eighth character selects the command: DPlus Link, Unlink, Information; g2_link Open, Terminate, What is linked. For a link command, the seventh character selects the remote reflector module. Unlink both applications before switching between DPlus and g2_link.

g2_link DTMF commands

These RF tone commands require g2_link_dtmf.sh running alongside g2_link. They control the local module receiving your transmission.

ActionDTMFExample
Unlink g2_link73Unlink the local module
g2_link status99Report the local module's link status
Link XRF#nnnmm#02102 → XRF021 B
Link DCSDnnnmmD04903 → DCS049 C

nnn is the three-digit reflector number. mm is the two-digit remote module number: 01=A, 02=B, 03=C, through 26=Z. The D prefix is the DTMF D tone.
