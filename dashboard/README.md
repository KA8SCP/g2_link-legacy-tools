# Unified Dashboard v0.4.2

Derived from WB1GOF's validated production export received October 12, 2026. Source archive SHA-256: `8b599f1cdb3cdf73b1fba5a07bb203509a82b28a629456f033745e0993570ce4`.

The release adds a shared `dashboard_config.php` and a per-site `dashboard.local.php` generated by the prompted installer. Callsign, timezone, input paths and RF-reference callsign are configurable; no W4CRL gateway settings are inferred from WB1GOF. The package is therefore a portable derivative, not byte-identical to that production export. `SHA256SUMS` describes this package's runtime files.

Run `bash scripts/check-release.sh` from the repository root. The PHP fixtures use isolated temporary copies and synthetic logs. Manual installations can copy `dashboard.local.php.example` to `dashboard.local.php` and adjust every setting. Never commit the generated local file.

See [installation](../docs/INSTALL.md) and [behavior](../docs/DASHBOARD.md). Production behavior was operator-verified on WB1GOF; the portable installer still requires gateway acceptance testing.
